# ml

Задел на будущее: дообучение своей модели для собеседований.

Здесь лежит **только обучение**, сервинг модели — в
[services/ai-service](../services/ai-service) (провайдер `local`).

## Целевая структура

```
ml/
├── data/          # сырые и подготовленные датасеты (в git не кладём, только скрипты/DVC)
├── notebooks/     # эксперименты
├── training/      # скрипты дообучения
├── eval/          # оценка качества модели против RouterAI
└── pyproject.toml # отдельные зависимости (torch и т.п.), не смешиваем с ai-service
```
