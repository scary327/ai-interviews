# 0003. Абстракция LLM-провайдера

**Статус:** принято

## Контекст
Сейчас используем RouterAI, в будущем возможна своя дообученная модель.

## Решение
Интерфейс `LLMProvider` в `ai-service/app/llm/base.py`. Остальной код
работает только с ним. Конкретная реализация выбирается через
`LLM_PROVIDER`.

Обучение (`ml/`) отделено от сервинга (`services/ai-service/`).

## Последствия
- Чтобы перейти на свою модель, достаточно добавить новую реализацию и
  поменять переменную окружения.
- Тяжёлые ML-зависимости (torch и т.п.) не попадают в образ API.
